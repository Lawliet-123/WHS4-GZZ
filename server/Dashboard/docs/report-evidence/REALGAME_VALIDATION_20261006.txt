이번에 확인한 것

승인된 비공개 방에서 실제 게임을 켜둔 상태로 Launcher와 수집기를 실행했습니다.
DLL 무결성, 외부 프로세스 접근, ESP, Hide Anywhere가 함께 실행되는 것을 확인했고,
180초 후 네 수집기가 모두 요청을 받아 종료 코드 0으로 종료됐습니다.
강제로 종료한 수집기나 남은 자식 프로세스는 없었고 게임은 그대로 유지됐습니다.

Shared 전송부터 Receiver, Scoring, Dashboard 조회 API까지 실제 로컬 HTTP로 연결했습니다.
빈 테스트 저장소에서 시작했고 합성 이벤트를 넣지 않았습니다.
수신한 506건의 이벤트 목록과 상세가 전부 일치했고,
overview, snapshot, 별도 최종 판정, 발신자 상태, Heartbeat 조회도 확인했습니다.
506건에는 정상 상태와 관측 실패 이벤트가 포함되므로 모두 핵 탐지라고 세지는 않습니다.

최종 판정은 두 대상 모두 INCONCLUSIVE, assessment_complete=false였습니다.
Hide 측정 불가와 ESP 정책 미확정이 남아 있기 때문에 정상으로 표시하지 않았습니다.
score와 confidence가 null인 경우도 0으로 바꾸지 않았습니다.
이번에는 요청에 따라 웹 화면 테스트는 하지 않았습니다.
전에 했던 React 연결 시험과 이번 실게임 API 시험은 별도 결과입니다.

추가한 실제 ESP Replay

normal_realgame_20261006_capture02
  NORMAL / Event 63건 / ESP 실행 없음
esp_realgame_20261006_capture01
  CHEAT / ESP / Event 82건 / ON 5706ms / OFF 80409ms
esp_realgame_20261006_capture02
  CHEAT / ESP / Event 67건 / ON 5189ms / OFF 77984ms

ON은 실제 게임 핸들을 연 시각, OFF는 ESP 프로세스 종료를 확인한 시각입니다.
카메라와 로컬 캐릭터의 읽기 준비 완료는 각각 19208ms, 17655ms이며,
그 뒤 최소 60초간 실제 새 읽기 성공을 확인했습니다.
각 ESP 프로세스에 직접 연결되는 탐지 이벤트는 12건, 11건입니다.
전체 건수에는 Windows 프로세스 등의 관측도 포함됩니다.
상대 플레이어 박스나 스켈레톤 표시까지 검증했다고 주장하지는 않습니다.

동일하게 실행 중인 게임에서 독립 캡처 세션으로 수집했고, 이전 로그를 복제하지 않았습니다.
실제 점수와 timestamp_ms, module=esp, 공통 Event 7필드를 유지했습니다.
정상 자료에 높은 점수가 있어도 삭제하거나 CHEAT로 바꾸지 않았습니다.
공개용 manifest와 events만 제출하고 원본 raw, 로컬 DB, 실패 기록은 올리지 않습니다.

앞서 보관 NORMAL 1개를 추가한 것까지 합쳐 요청받은 추가 CHEAT 2개, NORMAL 2개 수는
충족했습니다. 유효 ESP 자료는 총 CHEAT 3개, NORMAL 3개입니다.
threshold 2와 3 중 어느 것이 맞는지는 새 자료로 ReplayAnalyzer를 다시 돌려 판단해야 합니다.

이번에 고친 문제

격리된 실행 환경에서 Windows 사용자 프로필 환경 변수가 빠져 ESP 초기화가 실패했습니다.
필요한 실행 환경을 전달하도록 수정했습니다.
게임 생성 시각의 정수/실수 변환 차이 때문에 같은 게임인데 대상 불일치로 판단하던
검증 도구를 실제 수집기 계산 방식과 맞췄습니다.
Replay 준비 세션과 writer의 세션 ID가 다르던 문제를 고쳤고,
작업 객체 생성이나 연결에 실패했을 때 소유 자식 프로세스가 남지 않도록 보강했습니다.
실패한 실행 기록은 성공으로 바꾸지 않고, 조건을 충족한 새 캡처만 Replay로 제출했습니다.

아직 남은 것

Hide Anywhere는 현재 게임 빌드의 NamePool 바인딩과 맞지 않아
ERROR, measurement_valid=false가 발생했습니다.
프로세스가 실행됐다는 것만으로 정상 측정이나 전체 실게임 E2E 성공으로 보지 않습니다.
현재 빌드에 맞는 바인딩 확인은 해당 탐지기 담당자와 이어서 해야 합니다.

Launcher 통합 실행의 최초 Sysmon 조회가 512건 제한으로 잘려
엄격한 전체 coverage는 INCOMPLETE로 남겼습니다.
독립 Replay 캡처는 별도 준비 로그를 보존하고 측정 구간의 모든 필수 센서가
충분했을 때만 성공으로 내보냈습니다.

정상 Windows 프로세스의 VM_READ 접근과 오버레이가 높은 점수로 남는 사례가 있습니다.
일부 카탈로그 서명 파일은 현재 파일 단위 서명 검사에서 unsigned로 해석됩니다.
서명·허용 정책과 정상 표본 기반 점수 보강이 필요하며 OS PID 전체를 임의로 제외하지 않았습니다.
UE4SS와 관측 후크 DLL 예외, 등록/미등록 읽기 프로세스 대조 시험은 이번에 하지 않았습니다.
공개 사이트는 여전히 프론트 단독 DEMO이고 운영 인증·운영 API 연결은 별도 작업입니다.

정리 상태

테스트용 Sysmon 기능은 원래 Disabled 상태로 복원했습니다.
이벤트 로그는 지우지 않았고 재부팅, 게임 종료, 게임 파일 수정, DLL 주입은 하지 않았습니다.
소유 수집기와 임시 서버를 종료했습니다.
추가 Replay와 재현 도구는 GitHub 검토 브랜치에 반영하며 main 머지와 구분합니다.
