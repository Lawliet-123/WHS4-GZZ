양성 세션 상태

esp_calibration_20261007_run01은 PoC 실행 이전 warmup 관측 부족으로 실패했다.
성공한 CHEAT Replay로 내보내지 않았다. 첫 warmup은 Sysmon의 과거 512개 기록을
읽은 뒤 충분한 관측을 확립하지 못했다. 정확한 원인은 native probe로 확정하지 않았다.
재시험을 위해 과거 기록을 준비 단계에서만 prime하고 bounded warmup을 보완했다.
숨겨진 worker의 진행·오류 종류/단계는 개인정보 없는 JSON 진단으로 전달한다.
collector/sender의 종료 검증 후에만 새 Replay를 공개하고 중복 close를 제거했다.

별도로 EvtNext가 정상 열거 종료(259)를 실패로 처리해 이미 읽은 Event를 버리는
오류를 모의 API로 재현하고 최소 수정했다. EvtNext의 259만 종료로 처리하며
다른 API/오류와 truncated는 계속 실패/관측 부족이다. 이것을 실제 warmup 실패의
확정 원인으로 표현하지 않는다. 근거:
https://learn.microsoft.com/en-us/windows/win32/api/winevt/nf-winevt-evtnext

esp_calibration_20261007_run02 재시험은 Windows 권한 승인이 취소되어 실행되지 않았다.
실제 ESP ON 기능 관측 -> Server 저장 -> Scoring 양성 자료는 아직 미완료다.
없는 ON/OFF, remote draw, 실제 행동 시각, 잔존 확인을 만들어 넣지 않는다.

실행 안전 및 정리

기존 게임과 소유하지 않은 프로세스는 종료하지 않았다. 각 수집 세션은 별도
로컬 저장소를 사용했고 기존 운영 DB와 접속키는 사용하지 않았다.
두 disposable loopback 서버는 stop request로 종료했다.
자동 복원용 권한 승인은 취소됐지만 사용자가 관리자 PowerShell에서 Cleanup을
직접 실행한 뒤 원복을 다시 확인했다. 상태는 restored_disabled_no_log_clear,
기능은 Disabled, restart_needed=false다. Sysmon 서비스와 드라이버는 남지 않았다.
게임은 종료하지 않았고 테스트 포트 8002도 닫혔다. 재부팅·기존 로그 삭제는 없다.

최종 자동화 시험은 전체 ESP 246개, Dashboard backend 101개, Replay/export 26개
통과다. 이는 양성 실게임 세션이 완료됐다는 의미는 아니다.

Shared 7필드, production PID+생성 시각 제외, Receiver/Scoring/Launcher 계약,
원본 ESP 소스 및 threshold는 변경하지 않았다. LocalGuard YARA는 input_signature
담당의 별도 자료이며 이 DLL/ESP 시험을 production YARA positive로 제출하지 않는다.
