# Integrity 0.1.0 검증

2026-10-02 / Windows / Python 3.14.6.

- 실제 후보 ZIP을 독립 폴더와 client/SelfDefense/integrity 배치에 각각 풀어 검사.
- 각각 37개 테스트 통과. 같은 테스트를 두 배치에서 반복한 것이며 74개 서로 다른 항목은 아님.
- 배포된 shared 0.2.0 사용. 개발 작업 폴더에 기대지 않고 직접 실행·-m 실행·기본 경로 검색 검사.
- 정상·내용 변경·삭제·추가·범위 제외·읽기 실패·잘못된 기준·pin 변경·경로 제한·읽기량 제한 검사.
- 실제 로컬 HTTP 수신기에 shared 전송, 503 재시도 시 동일 ID 사용, 로컬/수신 JSON 일치 확인.
- Windows CTRL_BREAK_EVENT로 대기 중 정상 종료·manifest 마감 확인.
- 패키지 데모 6가지 상황의 상태와 종료 코드 확인. 모두 합성 자료이며 게임 테스트 아님.
- Python 3.12 문법 검사·문서 상대 링크 검사. 3.12 런타임 실행은 하지 않음.
- shared 0.2.0·watchdog 0.2.1 ZIP 해시 무변경 확인. Launcher 소스 수정 없음.
- 최종 ZIP은 검증한 코드와 동일하며 이 검증 문서만 확정함.

미검증: 실제 통합 Launcher, 팀 중앙 HTTPS receiver, 실제 배포본 기준·pin 적용, 게임 실행 중 성능, PyInstaller 패키징, 관리자 수준 공격자 방어.

정상 기준을 만들 때 사용하는 SHA-256 pin은 전자서명이 아니다. 배포본 기준은 사용자가 승인한 릴리스에서 별도로 만들어야 하며 이 ZIP에 실제 운영 기준을 넣지 않았다.

합성 데모와 단위 테스트는 정상/핵 게임 로그를 대신하지 않는다. 실행 방법은 [README](../README.md)를 참고한다.
