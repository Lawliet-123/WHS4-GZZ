# 수동 실측 기록

이 문서들은 06~10번을 격리된 테스트 VM에서 검증할 때 사용한 절차의 기록입니다. 원본 ZIP의 미리 빌드된 `.sys`, `.dll`, PDB는 공개용 소스 저장소에 포함하지 않았습니다. 필요한 시험 바이너리는 현재 소스와 WDK로 다시 빌드·서명해야 합니다. 커널 주소는 부팅마다 달라질 수 있으므로 과거 출력값을 재사용하면 안 됩니다.

- [06 함수 진입부](README-live06.md)
- [07 코드 무결성](README-live07.md)
- [08 자체 디스패치](README-live08.md)
- [09 목록 불일치](README-live09.md)
- [10 모듈 밖 시스템 스레드](README-live10.md)

과거 별도 실측의 PASS를 현재 설치 빌드의 PASS로 자동 해석하지 마세요. 현재 검증기의 과거 증거 가져오기는 모든 원시 값을 독립적으로 재계산하거나 빌드 해시를 대조하지 않습니다.
