# 12개 기능의 검증 범위

"오프라인"은 원본 검사 함수/분석기에 통제된 입력을 넣은 결과입니다. "라이브 지원"은 드라이버가 설치된 VM에서 실행할 수 있도록 구현했다는 뜻이며, 이번 작업에서 실행 완료했다는 뜻이 아닙니다.

| ID | 기능 | 구현한 자극과 판정 | 현재 한계 |
|---|---|---|---|
| 01 | 보호 대상 등록 | 전용 PID·생성 시각 등록, 시각 1틱 불일치 거부, 실패 후 정책 상태 보존, 종료 시 정책 해제 | 실제 PID 재사용 강제는 하지 않음. 라이브 실행 필요 |
| 02 | 프로세스·스레드 감시 | 드라이버를 연 뒤 대상 생성, 등록 뒤 새 스레드 생성·종료, 종료 시 `target_exit`, 정확한 PID/생성 시각/TID 대조 | 시작 전 기존 게임 DLL/스레드는 등록 이후 알림이 아니므로 기대하지 않음 |
| 03 | 게임 핸들 접근 | 프로세스 7종·스레드 6종을 각각 생성/복제하여 26회 검사. 시간·generation·actor/target/source/recipient·operation_id 대조, 독립 실제 권한 확인 | OS가 처음부터 요청을 거부한 경우 제한 성공으로 세지 않음. pre-only, 실패 post, 큐 손실 판정기는 오프라인 검사 |
| 04 | 일부 권한 제한 | observe/enforce pre/post 마스크 대조, 새 핸들로 테스트 버퍼 읽기/쓰기, 기존 읽기 핸들 유지 확인. 실제 access_policy.h C 테스트 | 실제 기존 쓰기 핸들 회수·커널 직접 접근 차단을 주장하지 않음. fail-open/self/kernel 예외는 기존 정책 함수 C 테스트 범위 |
| 05 | DLL·드라이버 로드 | 전용 DLL export 실행·새 매핑 base/경로/크기 대조. 선택적으로 전용 드라이버 서비스 로드와 kernel_image 대조 | DLL 경로·주소는 실제 smoke 확인. 드라이버 로드는 VM 미실행. 수동 매핑은 대상 아님 |
| 06 | 커널 함수 진입부 | 실제 integrity.h: 4개 함수 버퍼의 31번째 바이트 변화·복구, 범위 밖 32번째 바이트 음성 대조, 짧은 읽기/읽기 실패. 라이브 4개 읽기 상태 | 변경 테스트는 API 대역 사용. OS의 실제 함수 진입부를 패치한 실험은 NOT_RUN |
| 07 | 커널 모듈 코드 무결성 | 실제 code_scan.h + BCrypt: 기준 생성/같음/변경/반복 변경/복구, 데이터 및 폐기 실행 섹션 음성 대조, 섹션 설명자 변화, 할당/읽기 실패, 잘못된 PE, 기준 이전 변조. 라이브 순회 비교 | 실제 로드된 드라이버 코드의 변경 탐지는 미실행. 최초 기준의 신뢰성은 증명하지 않음 |
| 08 | 자체 디스패치 | 실제 integrity.h: 3개 주요 포인터 각각 변경·복구. 분석기 모듈 시작/끝 경계, 모듈 조회 실패. 라이브 현재값/기준값/소속 대조 | 대역 DRIVER_OBJECT만 변경. KernelSentinel 실제 디스패치를 교체한 실험은 NOT_RUN |
| 09 | 드라이버 목록 교차 | 실제 CrossView: 양 방향 차이, 3회 지속, 일시 로드/언로드, 0주소, 조회 실패/초기화. 라이브 Aux→PSAPI→Aux 세 번 대조 | OS 목록을 숨기지 않음. 차이 검증을 실제 은닉 드라이버 탐지로 세지 않음 |
| 10 | 시스템 스레드 출처 | 실제 thread_scan.h의 API 대역 C 테스트, ThreadOrigins 범위 경계/반복/재사용 TID·시각/조회 실패. 선택적 전용 드라이버 스레드 실제 소속 확인 | 19045 x64 이외는 판정 불가. 모듈 밖 커널 코드에서 스레드를 실제 실행하지 않음 |
| 11 | 콜백 동작 점검 | 라이브 조회 핸들 probe와 pre/post 대조. 기존 CallbackHealth: 누락·잘못된 operation/actor/generation·실패 post·큐 손실·지연·회복 | 실제 콜백을 제거하지 않음. 콜백 경로 외 전체 감시 정상 여부는 보증하지 않음 |
| 12 | 파일 식별·서명 | 실제 DLL 파일 SHA-256 계산/정책 일치, 원본 FileWorker 서명 조회. 빈 정책·이름/해시·서명 상태별 비악성 판정 회귀 | 기본 파일은 정상 테스트 DLL이며 실제 치트 샘플 분류 정확도 시험이 아님 |

## 아직 실제 환경에서 확인할 항목

- 드라이버 로드 후 `observe`, `enforce` 실행 결과와 설치된 보안 소프트웨어/다른 OB 콜백의 영향.
- 전체 모듈 순회 지연, 이벤트 부하·손실, 장시간 실행, 실제 게임/런처/오버레이 호환성.
- 독립 메모리 증거를 확보한 실제 커널 변조 실험. 이 패키지에는 OS 패치·은닉·수동 매핑 기능이 없습니다.

따라서 이 패키지는 기능별 검증 기반과 일부 실행 결과이며, "모든 치트 탐지 완료" 인증서가 아닙니다.
