# 공개용 정리 내역

제공된 `KernelSentinelValidation.zip`은 수정하지 않았습니다. 이 폴더는 소스만 별도로 추린 공개 준비본입니다. 선택적 자동 검증 경로의 호스트 보조 프로그램 소스는 같은 작업 공간에서 추가했습니다.

제외한 항목은 다음과 같습니다.

- `bridge.json`과 연결 토큰·KDNET 키
- `runs/`, `results/`, `reports/`의 실행 기록과 개인 경로
- 컴파일된 드라이버·실행 파일·DLL, PDB·오브젝트 파일
- 생성된 인증서·서명 파일, Python 캐시, Visual Studio 임시 파일
- 빌드별 체크섬과 오래된 일회성 패치·중간 결과 보고서

이 저장소의 `.gitignore`는 실행 후 다시 생성되는 같은 종류의 파일도 제외합니다. 원본 보고서를 공개하려면 개인 정보와 빌드 식별을 별도로 검토해야 합니다.
