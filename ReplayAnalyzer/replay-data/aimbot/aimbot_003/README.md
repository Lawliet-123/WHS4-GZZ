# aimbot_003 테스트 메모

## 테스트 조건

- 모듈: `aimbot`
- 분류: `cheat`
- 세션에서 여러 라운드를 진행함. 라운드 구분은 발사 횟수 초기화와 Hunter Actor ID 변경을 기준으로 정리함.
- **2라운드:** 에임봇으로 숨은 대상을 찾고, 발사는 수동으로 함.
- 원본 UE4SS 로그: `raw/meccha_aim_telemetry.jsonl`
- 공통 판정 스냅샷: `events.jsonl` (18행; 매 발사/확정 결과 시점의 누적 판정)

## 확인된 결과

`events.jsonl`의 `raw_score`는 이벤트가 들어올 때마다 다시 계산된 누적 점수다. 아래 점수는 각 라운드에서 기록된 최고값이며, 게임 전체의 최종 합산 점수는 아니다.

| 라운드 | 발사 시도 | 확정 명중 결과 | 최고 raw_score | 기록된 근거 |
| --- | ---: | ---: | ---: | --- |
| 1 | 7 | 1 | 8 | 숨은 대상 방향 반복 정밀 사격(3점), 이동 중인 숨은 대상 정밀 추적(1점), 명중 전 조준 수렴(3점) 및 조준 고정(1점) |
| 2 | 5 | 1 | 3 | 숨은 대상 방향으로 반복 정밀 사격(3점). 조준 수렴/고정 근거는 없음 |
| 3 | 3 | 1 | 4 | 명중 전 조준 수렴(3점) 및 조준 고정(1점) |

2라운드는 에임봇으로 대상을 찾았더라도 발사는 직접 했다는 테스트 메모를 반드시 함께 전달한다. 이 라운드에서는 조준 수렴/고정 신호가 나오지 않았고, 숨은 대상 방향 반복 사격 신호만 나왔다. 이는 해당 신호가 에임봇 사용 자체를 단독으로 확정한다는 뜻은 아니다.

## 판독 시 주의

- `manifest.json`의 `cheat_windows_ms`는 현재 `[0, 268675]`로, 캡처 스크립트에 `--cheat-window`를 주지 않아 세션 전체가 에임봇 사용 구간으로 기록됐다. 실제 F8 사용은 간헐적이었으므로 이 구간을 실제 ON/OFF 시간으로 간주하면 안 된다.
- `aim_trace_admin.csv`에는 F8 활성 샘플이 기록되어 있으나, 그 시간은 에임 트레이스 실행 후 경과시간이다. 게임 세션의 `timestamp_ms`와 기준점이 다를 수 있으므로 별도 기준시각 확인 없이 두 타임라인을 직접 대응시키지 않는다.
- 점수는 정상/핵 최종 판정이 아니라 이 모듈의 `raw_score`다. ReplayAnalyzer에서는 라운드별 조건과 실제 F8 사용 여부를 함께 고려한다.
- `player_id`에는 UE 액터 경로가 들어 있다. 공통 스키마의 짧은 ID 규칙과 맞지 않을 수 있으므로 중앙 전송 검증과는 별개로 취급한다.
